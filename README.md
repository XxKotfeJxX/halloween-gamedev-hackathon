# Halloween Gamedev Hackathon

Готовий статичний сайт українською. Збірка й встановлення пакетів не потрібні.

- `dist/index.html` — головна сторінка. Для хостингу завантажте всю папку `dist`.
- `dist/standalone.html` — автономна сторінка: шрифти, стилі, скрипти й зображення вже всередині. Можна відкривати локально без інтернету; зовнішні посилання потребують мережі.
- `dist/animation.html` — окрема демонстрація шарів ілюстрації.
- `dist/assets/partners-data.js` — список організаторів і партнерів.

## Організатори та партнери

Поточний порядок: prof_IKNI, кафедра систем віртуальної реальності НУЛП, Ігровари, tsukat, Майстерня Рольовика, Хобі Монстр, Дайс Кон, Мальопус, EPAM, Lionwood Software, DataArt. Сім нових учасників погоджено користувачем 28.10.2026 для додавання на GitHub. Кафедру АСУ вилучено за уточненням організатора. GSC Game World та Octopus не додані: участь ще не підтверджена.

Щоб додати учасника, додайте об’єкт у `window.HALLOWEEN_PARTNERS`:

```js
{ name: 'Назва', logo: 'assets/partners/logo.svg', href: 'https://example.com/' }
```

Без логотипа можна вказати `wordmark: 'Назва'`. Для кафедр є `kind: 'department'`. Для темного логотипа додайте `logoSurface: 'light'`, щоб отримати невелику світлу підкладку; для компактного SVG-вордмарка — `logoClass: 'partner-logo-wide'`. До шести учасників включно показується компактна сітка; більша кількість автоматично вмикає горизонтальну стрічку зі стрілками, свайпом та клавішами Left/Right/Home/End. Автогортання немає. Нуль учасників приховує розділ. На телефоні сітка має дві колонки, остання непарна картка центрована.

Єдине джерело списку — `dist/assets/partners-data.js`. Додайте або видаліть об’єкт у цьому файлі; для нового логотипа покладіть файл у `dist/assets/partners/`. Звичайний сайт підхоплює зміни автоматично. Після коміту в `main` GitHub Actions оновлює резервний HTML для вимкненого JavaScript та `dist/standalone.html` і зберігає їх окремим комітом. Дочекайтеся зеленого статусу **Update static exports** перед завантаженням ZIP. Вручну дублювати список у HTML не потрібно. Локально ту саму синхронізацію запускає `python3 scripts/export-standalone.py` (потрібні Python 3.9+ та Node.js; зовнішніх пакетів немає). Це оновлення файлів репозиторію; для зовнішнього хостингу потрібен його звичайний деплой.

## Вигляд і рух

Суцільна темна оливково-вугільна палітра, теплі помаранчеві акценти, приглушені картки й м’які переходи між секціями. Привид літає по всьому блоку «Сюжет», включно з текстом. Декор не перехоплює натискання; ілюстрація героя не виділяється й не перетягується.

Світлий/темний гарбуз, комп’ютер та череп екрана — окремі шари. Блимання гарбуза (8,3 с), гліч екрана (11,7 с), сканування (4,8 с) незалежні. Якщо якийсь шар не завантажився, залишається цілісна резервна ілюстрація. Кнопка в шапці вмикає/вимикає анімації, запам’ятовує вибір; за замовчуванням враховується `prefers-reduced-motion`. Текст видимий навіть при затримці скриптів.

Шрифти Creepster, Oswald та IBM Plex Mono й усі ресурси головної сторінки збережені локально. WebP використовується для швидкого показу, оригінальні PNG збережені для редагування. PNG гарбуза та комп’ютера мають спільне полотно 1024×1536; череп екрана — окреме зображення. Ілюстрація створена ImageGen; контури світлого й темного кадрів не гарантуються побітово однаковими.

## Перевірено

Мобільна й планшетна сітка, списки з 1, 4, 5 та 12 учасників, кнопки гортання, перемикач руху, завантаження шарів і резервне зображення при відсутньому шарі.

## Мобільна версія

Окремий макет для екранів до 600 px: велика афіша, дата поруч з ілюстрацією, текст збоку й широка кнопка. Нижче — заголовок зі зміщеними рядками, асиметричні ролі, мозаїка фактів та компактні партнерські картки.

- Торкання гарбуза запускає короткий рух ілюстрації, гліч екрана й трьох кажанів. Це звичайна доступна кнопка; вона також працює з клавіатури. На десктопі цей мобільний елемент прихований.
- Програму можна гортати нативним горизонтальним свайпом, стрілками або клавішами Left/Right/Home/End. Лічильник показує поточний день, крайні стрілки вимикаються. Без JavaScript залишається нативна прокрутка.
- Після першого екрана з’являється компактна панель реєстрації. Вона ховається, коли фінальний блок потрапляє на екран, і не лишає приховане посилання в порядку клавіатурного фокусу.
- Невеликий паралакс і поява рядків/карток під час скролу. При вимкнених анімаціях рух, гліч від торкання й кажани не запускаються; контент і навігація доступні.

Код: `assets/mobile.css`, `assets/mobile.js`. Усі реакції локальні: немає запитів доступу до сенсорів чи сторонніх бібліотек. Перевірено макети 320/390 px, гортання до третього дня, реакцію на кнопку, вимкнення анімацій, приховування панелі біля реєстрації та десктоп. Реальний жест на фізичному телефоні не перевірявся в цьому середовищі.
